# GrowWithJoshua

Website for GrowWithJoshua, the e-commerce consultancy of Ayomide Joshua. It's a static site hosted on GitHub Pages.

## Editing

- **Contact details:** change `SITE` at the top of `assets/js/main.js`
- **Your photo:** add `assets/img/joshua.jpg`, then uncomment the `<img>` line in `about.html`
- **Achievements:** replace the placeholder entries in `achievements.html`
- **Colours and fonts:** edit the `:root` variables at the top of `assets/css/style.css`
